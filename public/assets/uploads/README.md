# public/assets/uploads

Каталог сохранён как **legacy-заглушка** и не используется CMS.

Актуальный медиа-слой Keystatic:

- файлы загружаются в `src/assets/uploads/`;
- в контенте сохраняется путь вида `/assets/uploads/<slug>/<file>`;
- оптимизация (WebP, ресайз) выполняется на этапе сборки через `astro:assets`
  и [`src/lib/image.ts`](../../../src/lib/image.ts).

Файл `.gitkeep` оставлен, чтобы каталог существовал в репозитории и не ломал
старые ссылки на `/assets/uploads/...` при статической раздаче.
